# Scene artwork

## Rainy window

- Artist: **jaymeehuynh / FadingPixels**.
- Source: https://opengameart.org/content/animated-lofi-pixel-art-background-320x180
- Download: https://opengameart.org/sites/default/files/rainybywindowbg_byfadingpixels.zip
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), as declared on the source page.
- `rainy-window.png`: unchanged quiet frame 20, retained as a usable static wallpaper.
- `rainy-window.gif`: source PNG sequence converted to 320×180 at 100 ms per frame, with the four lightning frames omitted and sequence rotated to start on a quiet frame. Loops indefinitely.

## Moonlit city, forest, snow mountains

- Artist/publisher: **SpritePilot**.
- Source and license declaration: https://spritepilot.com/free-game-assets/backgrounds
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `city.png`, `forest.png`, `snow.png`: unmodified 384×216 whole-scene PNG downloads from `/free-assets/backgrounds/{night-city,forest,snow-mountains}/`.

## Bonfire

- `bonfire.png`: original AI-generated artwork created for Lofiji with the imagegen skill, then resized with nearest-neighbor sampling to 480×270.
- Prompt: a quiet pixel-art campfire beside a moonlit lake and pine forest, with an open dark sky for the clock and restrained amber/indigo colors.
- Included with the project's MIT license, to the extent copyright applies.

All assets were retrieved/created on 2026-11-16. Scene images are embedded in the executable; custom PNGs and GIFs can replace them through Settings.
